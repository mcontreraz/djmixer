Open-source DJ software in the league of Serato and Traktor.
Free for everyone, forever.

DJMixer is a native DJ application (C++17 + Qt 6) built from scratch by a team of AI agents with one human in charge. Not a web wrapper, not a mockup: a real-time audio engine whose loop render path allocates nothing.

Lite free forever Open source (GPL-2.0-or-later) macOS first 2 decks · key lock · beatgrid · MIDI

The promise

The Lite edition launches free for everyone and stays that way. No price, no fee, no subscription, no trial that expires. It is not a launch promotion: it is the reason the project exists - so any DJ who wants to be a DJ can start without monthly fees or expensive software.

A paid Pro will exist, for what a DJ needs once they grow (stems, recording, DVS, advanced key analysis) and never for the essentials of mixing.

The commitment is versioned in the repository (docs/promise.md) and overrides any other text. The complete source ships with the first binary: that is a GPL obligation, not a marketing promise.

This is what it looks like

Two decks with the same track: 129.26 BPM detected, key 5B in Camelot, 8 hot cues per deck, auto-loops on the beatgrid, 3-band EQ + filter + FX per channel, and the RGB waveform with the beat markers. Synthetic demo audio.

The library analyses on its own: BPM and key for every track, cached on disk.

SyncLab: the sync engine with each deck's downbeat, the bar phase and the offset measured in milliseconds. On the synthetic demo it lands at +0.0 ms.

Technical specifications

What is built, and how. The 17 complete specs are in specs/, with their plan, tasks and contracts.

AreaStateTechnical detail
EngineDoneCallback thread with no locks and no UI access. The loop path does not allocate; the general playback path reallocates the buffer when the sample count changes. PCM cache, seqlock, SPSC queues. 48 kHz.
DecksDone2 decks + crossfader, cue, seek, PFL, 8 hot cues per deck with a persistent .hotcues sidecar.
TempoDonePitch/tempo, vinyl mode, continuous pitch-bend, key lock (tempo without changing pitch).
Key lockDoneRubber Band engine (GPL-2.0-or-later) in realtime, with input and output crossfade. The own WSOLA prototype was discarded.
KeyDoneKey detection in Camelot notation, cached per track.
BeatsBeing validatedBPM and downbeat detection, beatgrid, Serato grid import. The automatic detector is still being validated against real tracks.
LoopsDoneAuto-loops 1/8…16 beats on the beatgrid, deferred resize (never hot).
SyncDonePhase correction, compensating the audible latency of the key lock. SyncLab to inspect the downbeat in ms.
MixerDone3-band EQ, filter, FX per channel, isolator, master VU.
WaveformDoneRGB with detail at 200 buckets/s, colour overview, 2–64 s zoom.
ScratchDoneContinuous, without audible granulation.
MIDIDoneFull mapping, jog sensitivity, pitch-bend.
DecodingDoneMP3, FLAC, AAC, MP4/M4A, Opus (AV1+Opus via stream-copy).

What does not work yet is written down, not hidden. Automatic beat detection is still being validated against real tracks; the site says so in the same sentence where it says what works.
