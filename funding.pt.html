Apoie o DJMixer

A versão Lite é gratuita para todo mundo, para sempre. O que se pede aqui é o custo de manter a equipe de agentes que a constrói: capacidade de modelos, hardware para testá-la e a assinatura de código para o download não chegar com avisos.

O compromisso

A Lite é lançada gratuita para todo mundo e continua assim: sem preço, sem mensalidade, sem assinatura, sem trial que expire. Existirá uma versão Pro paga para o que um DJ precisa quando cresce (stems, gravação, DVS), nunca para o essencial de misturar. O compromisso está versionado no repositório e prevalece sobre qualquer outro texto.

O pedido

O gargalo real é a capacidade de modelos de IA que a equipe de quatro agentes (CTO, Coder, QA, Growth) consome. Cada decisão de motor, cada estudo de referência e cada iteração de testes custa tokens. É isso que trava o lançamento.

Meta do primeiro trecho: USDC 500 - um mês de capacidade da equipe, a assinatura para o download não chegar com o aviso do Gatekeeper e o domínio. O primeiro desbloqueio são USDC 99: a conta Apple Developer, que é o que realmente tem o lançamento travado. USDC 2.000 é o próximo degrau (vários meses mais hardware de referência).

O que o dinheiro paga

Capacidade de modelos para a equipe de agentes, um MIDI controller para validar com hardware real e a conta Apple Developer (99 USD/ano) para o download sair assinado e sem o aviso do Gatekeeper.

Sem cripto também

GitHub Sponsors e Patreon abrem com a primeira doação. A Lite é grátis de qualquer forma: não doar não te coloca numa lista de recursos menor.

O álbum vem junto

A Lite é lançada com o álbum completo de McBaez, grátis. O projeto de software e o projeto musical são o mesmo.

O artista

Relaunch, de McBaez (McDiscJockey) - deep garage / 2-step '90s. Uma escuta é uma reprodução; se gostar, é um like. O canal onde isso continua é o McDiscJockey.

Conformidade

Isto é uma doação, não um investimento: não há token, participação ou promessa de retorno. Doações podem ser income tributável para quem doa (no Chile, o SII) - cada doador deve consultar seu contador; o projeto não dá orientação tributária. O endereço é exclusivo do projeto.
