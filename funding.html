Apoya DJMixer

La versión Lite es gratis para todo el mundo, para siempre. Lo que se pide aquí es el coste de mantener el equipo de agentes que la construye: capacidad de modelos, hardware para probarla y la firma de código para que la descarga no salga con avisos.

El compromiso

La Lite se lanza gratis para todo el mundo y lo seguirá siendo: sin precio, sin cuota, sin suscripción, sin trial que expire. Existirá una versión Pro de pago para lo que un DJ necesita cuando crece (stems, grabación, DVS), nunca para lo esencial de mezclar. El compromiso está versionado en el repo y manda sobre cualquier otro texto.

El pedido

El cuello de botella real es la capacidad de modelos de IA que consume el equipo de cuatro agentes (CTO, Coder, QA, Growth). Cada decisión de motor, cada estudio de referencia y cada iteración de tests cuesta tokens. Eso es lo que frena la release.

El primer unlocking son USDC 99: la cuenta de Apple Developer, que es lo que de verdad tiene la release bloqueada. USDC 2.000 es el siguiente escalon (varios meses mas hardware de referencia).

Qué paga el dinero

Capacidad de modelos para el equipo de agentes, un MIDI controller para validar con hardware real y la cuenta de Apple Developer (99 USD/año) para que la descarga salga firmada y sin el aviso de Gatekeeper.

Cumplimiento

Esto es una donación, no una inversión: no hay token, ni participación, ni promesa de retorno. Las donaciones pueden ser ingreso imponible para quien dona (en Chile, el SII): eso lo consulta cada uno con su contador, el proyecto no da consejo fiscal. La dirección es de uso exclusivo del proyecto.
